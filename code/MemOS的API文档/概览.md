# MemOS API 总览文档
## 一、API 简介
MemOS 目前提供两类 API，助力开发者存储和检索对话记忆，具体如下：
1. **记忆 API（Memory API）**：检索用户的相关记忆片段，使模型生成的响应能够融入用户的历史记录、偏好和上下文信息；
2. **消息 API（Message API）**：添加和检索用户与系统之间的原始对话消息，支持存储完整的对话记录。

## 二、身份认证
所有 API 请求均需进行身份认证，确保每个请求的 `Authorization` 请求头中包含你的 API 密钥。

## 三、项目管理
MemOS 支持按项目维度管理资源、权限和调用日志。一个项目可以是一个应用、一个智能体，或任何需要独立资源管理的模块。

### 1. 创建项目
- 每位新用户默认拥有一个项目；
- 通过控制台创建新项目时，输入项目名称和描述即可生成独立项目。

### 2. 删除项目
- 若拥有多个项目，可删除不再需要的项目；
- 注意：删除项目会清除该项目下的所有记忆、消息及相关数据，此操作不可撤销。

### 3. API 密钥（API Keys）
- 每个项目都有专属的 API 密钥列表，用于访问该项目下的所有记忆、消息和数据；
- 在控制台左上角切换项目，即可查看对应的 API 密钥。

### 4. 调用日志（Call Logs）
- 在控制台左上角切换项目，可监控该项目的 API 使用情况和调用历史。

## 四、后续步骤
1. 注册并登录 MemOS 云平台，获取你的 API 密钥；
2. 查阅各 API 的详细文档，了解请求与响应格式、参数说明及使用示例，相关文档包括：
   - Add Message（添加消息）
   - Search Memory（搜索记忆）
   - Get Message（获取消息）
   - Error Codes（错误码）
3. 发起首次 API 调用，添加或检索记忆数据。
